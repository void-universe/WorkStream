# CHANGELOG

A version number only holds at the moment a tag is cut: `package.json` is currently `0.1.2`, the newest tag is `v0.1.2`, so the first section below is called **0.1.2 (1.0.0 candidate)** -- it records the capabilities already merged into `main` and already pinned into `npm run qa`. The source of truth for feature behavior itself remains [docs/guide.en.md](docs/guide.en.md) and [docs/arch/scheduler.en.md](docs/arch/scheduler.en.md); this file only records "which merge brought what" and "what is still missing", without copying a second manual.

## 0.1.2 (1.0.0 candidate)

- Self-check floor: `npm run qa` **865 checks, 0 failures** (the count follows the final summary line; the floor is recorded in [AGENTS.md](AGENTS.md) and may only go up, never down).
- README reduced to a short front page: positioning, what it does, quick start and deploy; the long-form how-to for each capability moved into the paired [docs/guide.en.md](docs/guide.en.md), the document-pairing gate pins that pair too, and the site's documentation grid gains a guide card.
- Migrations `sql/0001_init.sql` -> `sql/0014_vm_gateway.sql` are in place alongside the code; the deployed environment's database is still empty and not one of the fourteen migrations has ever been applied -- see "Not finished yet" for why.
